# Harness snapshots

The harness the loop grew over the 20-task curriculum, at the three points the paper evaluates.
Each folder holds `Skills/`, `Tools_code/` and `prompt_files/`. Diff two of them to see what the
curator added.

| Folder | Paper name | Internal snapshot | State |
|---|---|---|---|
| `H_00` | H<sub>0</sub> | `H_00` | The hand-built starting harness |
| `H_10` | H<sub>10</sub> | `H_07` | After 10 curriculum tasks |
| `H_20` | H<sub>20</sub> | `H_14` | After 20 curriculum tasks |

Snapshots were numbered once per accepted merge, not per task, so the internal numbers differ from
the paper's. `MILESTONES.md` and each folder's `VERSION_B_NOTE.md` record the mapping and the
history, including the places the main run was helped by hand.
