# 01_datestone_1934

**Art-deco datestone**

Reference: reference.png

Other plates for this task (the unedited original, crops) are in
`reference/`: original.jpg.

Only a few basic instructions (everything else is yours to plan and work out):-

Model the art-deco datestone in the reference. Do it in two steps: first the block
with the numerals centred on the face, then a sculpting and texturing pass.

Each of the panel's four corners carries three incised vertical grooves of graduated
length. Sculpt those rather than modelling them, and bake the result down to
texture. Use sculpting for the surface damage and wear as well, alongside
conventional textures.

No need for fancy lighting -- keep it simple. Same for the camera: pick a
sensible view that shows the object and move on. Do not spend actions hunting
an exact match to the reference framing.
