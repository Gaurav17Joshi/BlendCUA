# 08_shark

**Great white shark**

Reference: reference.png

Only a few basic instructions (everything else is yours to plan and work out):-

Model the great white shark in the reference. This one is not low poly -- keep
enough geometry for the body form to read properly. Use sculpting for the form and
the surface detail, and texture painting for the grey-to-white countershading, the
gill slits and the scars. Make the body follow the shark image, so that the image itself
can be used as the texture (look at step 5 of the bat plan, plans/Bat/Bat_plan.md: put the
shark image in Blender and fit the model to it). Then make the fins and the tail as their own
pieces: trace each one from the image, build it as a thin mesh pushed out from the body at its
root, and texture it with the fin's own region cut out of the same image.

Then rig it and animate it swimming. (Note get the animation in viewport shading to
speed it up)

The reference is a single side view, so use gpt-image-2 to get front and top views
first.

No need for fancy lighting -- keep it simple. Same for the camera: pick a
sensible view that shows the object and move on. Do not spend actions hunting
an exact match to the reference framing.
