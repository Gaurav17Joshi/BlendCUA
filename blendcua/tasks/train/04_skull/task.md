# 04_skull

**Human skull**

Reference: reference.png

Other plates for this task (the unedited original, crops) are in
`reference/`: original.jpg.

Only a few basic instructions (everything else is yours to plan and work out):-

Model a low poly skull using the reference. Basic idea would be to make the overall shape first, and then make circular holes for eyes, etc .

The reference is a single three-quarter view, so use gpt-image-2 to get front and
side views from it first. (And use them well more than the angled reference image)

The rough ouline should be that 1 step to make the low poly head mesh HM, 1 step to make the eyes and nose depression on the mesh HM, another to make the teeth, lower jaw etc.

No need for fancy lighting -- keep it simple. Same for the camera: pick a
sensible view that shows the object and move on. Do not spend actions hunting
an exact match to the reference framing.
