# 07_sneaker

**Running shoe**

Reference: reference.png

Other plates for this task (the unedited original, crops) are in
`reference/`: original.jpg.

Only a few basic instructions (everything else is yours to plan and work out):-

Model the running shoe in the reference as a low-poly model. No need to model the fine details of the cloth, 
but it should have the basic strucuture, features, texture and the nike logo.

Put the panel structure, the side logo and the sole tread into textures instead.

Measure with scripts, in the plan and in every step that builds a shape: before building,
saved Python scripts read the reference (mask the parts, mark the key points such as heel,
tongue peak, toe and the sole-to-upper line, trace the outlines, draw the read back on the
image), and the build takes its sizes and boundaries from those files, not from memory.

No need for fancy lighting -- keep it simple. Same for the camera: pick a
sensible view that shows the object and move on. Do not spend actions hunting
an exact match to the reference framing.
