# 12_newtons_cradle

**Newton's cradle**

Reference: reference.png

Other plates for this task (the unedited original, crops) are in
`reference/`: original.jpg.

Only a few basic instructions (everything else is yours to plan and work out):-

Model the Newton's cradle in the reference -- the chrome tube frame on its black
base, five polished balls, each hung on a V of thread from the two top rails -- then
set the balls up as rigid bodies with the threads as constraints, lift the end ball,
and simulate the swing. (Get the animation in viewport shading to speed it up.)

The reference is a photograph of the swing in progress, so what you are matching
is the motion -- deliver it as an animation.

No need for fancy lighting -- keep it simple. Same for the camera: pick a
sensible view that shows the object and move on. Do not spend actions hunting
an exact match to the reference framing.
